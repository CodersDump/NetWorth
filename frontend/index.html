Merge duplicate profiles

Fixes the same person having 2+ separate profiles (usually from a registration with no group, so their matches were invisible on the roster they actually played in - fixed going forward, but existing duplicates still need merging by hand). Picks one profile to keep; the other's matches, group memberships, and open sessions all move onto it, then the merged-away profile is deleted. If it has a linked login and the kept profile doesn't, the login moves too.

Refuses automatically if either profile has played in a tournament or has a finance record, or if both already have their own separate login - those need to be resolved by hand first.

Feature settings
Let new players create a profile instantly (skip approval)

Off by default: a new sign-up's "create profile" goes to the request queue above. Turn on during a busy session so new people can start playing without waiting. Claiming an existing profile always needs approval.

Show levels, coins, store & quests to everyone

Off during soft launch (admin-only preview). Flip on to reveal the whole gamification layer - level under the banner, coin balance, the Store tab, and weekly quests - to all players.

Private mode (players can cloak their stats)

Lets a player go private: their stats drop out of rankings, Hall of Fame and head-to-heads for everyone, and in return they lose those comparative views themselves. You (admin) always see all data.

Seasons (soft-reset leaderboard)

Everyone starts each season near 1000 and climbs; all-time rating is untouched.
